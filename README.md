# 🌦️ WeatherDesk

A modern and responsive weather application that provides real-time weather information for any city.

## ✨ Features

* 🌍 Search weather by city
* 🌡️ Real-time temperature and weather conditions
* 💧 Humidity information
* 💨 Wind speed
* 📊 Atmospheric pressure
* 👁️ Visibility information
* 🌧️ Weather forecast
* 🕘 Recent searched locations
* 📱 Responsive and user-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Weather API
